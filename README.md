# 김지수 캐릭터 포트폴리오

AI 활용 캐릭터 크리에이터 포트폴리오 웹앱입니다. 휴대폰 화면 기준으로 만들었어요.

1. 슈가소녀 인트로 영상
2. 자기소개 (ABOUT ME)
3. 작업물 8편: 참아와 질러 · 퍼니팜 레몬소녀 · 출근 비행 · 한장이 이모티콘 · 한장이 IP 제안 · 한장이 숏폼 · 보였다면 멈췄을 겁니다 · 지수랩 제안서

작업물 이미지는 탭하면 확대되고, 영상 자리의 플레이 버튼을 누르면 영상이 재생됩니다.

## 파일 구성
- `index.html`: 페이지 전체 (별도 빌드 없음)
- `assets/`: 웹용으로 압축한 영상, 작업물 이미지
